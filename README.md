# Medical Health Assistance System for Students and Faculty
Python + Flask backend, HTML/CSS/JS front end, SQLite database (D1-D4 tables). Works on Windows and Linux.

## Run
    pip install -r requirements.txt
    python app.py          # open http://127.0.0.1:5000
    python tests.py        # runs TC01-TC05 (black box) and white box tests
